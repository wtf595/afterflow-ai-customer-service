PRODUCT DECISION RECORD

技术能力，最终体现在取舍。

这不是一份“术语大全”，而是一套围绕业务风险、效果证据和成本约束展开的产品方案。

推荐方案

RAG + Workflow
而不是自主 Agent

固定流程能覆盖多数售后问题；只有任务步骤无法预先定义时，Agent 的自主规划才值得承担额外成本与不可控性。

SCOPE

首版做什么

  • ✓识别二类售后意图与置信度
  • ✓查询订单状态和基础物流事实
  • ✓检索政策并展示依据来源
  • ✓生成可编辑客服草稿
  • ✓高风险识别与人工接管
NON-GOALS

首版明确不做

  • ×自动退款或执行资金操作
  • ×未经授权承诺赔偿
  • ×无人审阅直接对客发送
  • ×训练私有硬件模型
  • ×让 Agent 自主跨系统操作
